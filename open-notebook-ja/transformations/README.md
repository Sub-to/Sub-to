# 日本語のトランスフォーメーション（変換）プロンプト集

Open Notebook の「変換」は、ソースに対して LLM を実行して洞察（インサイト）を作る機能です。
プロンプトはユーザーが完全に書き換えられます。上流のテンプレートは実質

```jinja
{{ instructions }}
（数式の書式指定）
# INPUT
```

なので、**ここに書いた日本語がそのまま指示になります**。英語ソースからでも日本語の洞察が作れます。

## 登録方法

1. ナビゲーションの **変換（Transformations）** を開く
2. **新規** を押す
3. 名前・説明を入れ、下のプロンプトを「プロンプト」欄に貼り付ける
4. 保存し、ソース画面から実行する

各変換には個別にモデルを割り当てられます（v1.14.0 で実際に反映されるよう修正済み）。
長い文書の要約には大きめのモデル、定型抽出には安いモデル、と使い分けられます。

---

## 1. 日本語要約

> 名前: `日本語要約` / 説明: `どの言語のソースでも日本語で要約する`

```
あなたは日本語で書く優秀なリサーチアシスタントです。
以下の文書を日本語で要約してください。ソースが英語などの外国語であっても、要約は必ず日本語で書きます。

出力形式:

## 一言でいうと
（この文書が何を言っているかを1〜2文で）

## 要点
- （重要な主張を5〜7個。各項目は1〜2文で完結させる）

## 数字・固有名詞
- （文書中の具体的な数値、企業名、製品名、人名を、原語表記を保ったまま列挙する。なければ「特になし」）

## 読むべき人
（この文書が誰にとって有用かを1〜2文で）

制約:
- 文書に書かれていないことを補わない。推測が必要な場合は「（推測）」と明示する。
- 定着した技術用語は原語のまま使うか「日本語（原語）」の形で書く。
- 文体は「です・ます」調で統一する。
```

## 2. 重要ポイント抽出

> 名前: `重要ポイント` / 説明: `箇条書きで論点だけを日本語で取り出す`

```
以下の文書から、重要なポイントだけを日本語の箇条書きで抜き出してください。

ルール:
- 1項目1論点。1項目は40〜80字程度。
- 重要度の高い順に並べる。最大10項目。
- 原文にある数値・日付・固有名詞は原語表記のまま残す。
- 文書に書かれていないことは書かない。
- 各項目の末尾に、その根拠が文書のどのあたりにあるか（章題や小見出し）を丸括弧で添える。
  章題がない場合は省略してよい。

出力は箇条書きのみ。前置きも結びも不要です。
```

## 3. 用語集（日英対訳）

> 名前: `用語集` / 説明: `英語ソースの専門用語を日本語対訳付きで一覧化する`

```
以下の文書に出てくる専門用語・略語・固有名詞を抽出し、日本語の用語集を作ってください。

出力形式（Markdown の表）:

| 用語（原語） | 日本語 | 文書中での意味 |
|---|---|---|

ルール:
- 「日本語」列は、定訳があればそれを使い、なければ原語のままにして「（定訳なし）」と付す。
- 「文書中での意味」は、一般的な辞書的定義ではなく、この文書での使われ方を40字程度で書く。
- 一般的すぎる語（data, system など）は入れない。読者がつまずきそうな語に絞る。
- 最大20語。多い場合は重要な順に絞る。
```

## 4. 批判的レビュー

> 名前: `批判的レビュー` / 説明: `主張の弱点・前提・反証可能性を日本語で洗い出す`

```
あなたは慎重な査読者です。以下の文書を批判的に読み、日本語で講評してください。

## 中心的な主張
（この文書が読者に信じさせようとしていることを1〜3個）

## 根拠の強さ
（主張ごとに、提示されている根拠と、その強さの評価。データの出典、サンプル数、
　比較対象の有無に注目する）

## 明示されていない前提
（著者が当然視していて、文書中で検証されていない前提）

## 反証されうる点
（どんな事実やデータが出てくれば、この主張が崩れるか）

## 判断を保留すべき点
（文書だけでは判断できず、追加で確認が必要なこと）

ルール:
- 論調ではなく論理を評価する。著者の立場や属性への言及は避ける。
- 文書に書かれていない事実を持ち込まない。外部知識を使う場合は「（文書外の知見）」と明示する。
- 妥当な部分は妥当だと書く。批判のための批判をしない。
```

## 5. 日本語Q&A生成

> 名前: `想定問答` / 説明: `文書の内容から日本語のQ&Aを作る`

```
以下の文書をもとに、日本語で想定問答を作ってください。

出力形式:

### Q1. （質問）
A. （回答。文書の記述だけを使って3〜5文で）

質問は次の配分で合計8問作ってください:
- 事実確認（文書に直接書いてある）: 4問
- 理解の確認（文書の内容を組み合わせて考える）: 3問
- 限界の確認（この文書では答えられないこと）: 1問
　※最後の1問の回答は「この文書には記載がありません。確認するには〜」の形で書く。

ルール:
- 回答に文書外の知識を混ぜない。
- 数値や固有名詞は原語表記のまま引用する。
```
