## 🧠 What I'm building

### ⚡ [MYLN-FRAME](https://github.com/Sub-to/myln-frame)
A lightweight AI inference framework inspired by the **myelin sheath** — the biological insulator that makes neural signals fast.

- No GPU · No framework · No cloud
- Swappable specialist heads (swap domain, keep the frame)
- 2-stage cascade: **9 µs** fast path → **118 µs** precise path
- Runs on Raspberry Pi 5, old laptops, embedded boards
- Universal C API → Python / Node.js / Ruby / Go / Rust
